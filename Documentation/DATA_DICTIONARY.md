# Core data dictionary
- User: account identity, role and credentials (demo only).
- Station: name, address, coordinates, capacity and operating status.
- PowerBank: serial, status, battery percentage (simulated metadata only), station.
- Reservation: customer, station, device, pickup code, expiry and status.
- Rental: customer, device, reservation, start/end, status and price snapshot.
- ReturnRecord: rental, return station, timestamp, simulated cost and inspection status.
- MaintenanceRequest: target, description, priority and status.
